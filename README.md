# 🛒 Grocery Shop Billing System in Excel (VBA)

An automated billing and inventory tracking system built using **MS Excel** and **VBA (Visual Basic for Applications)** to streamline daily store operations.

---

## ✨ Key Features
- 🧾 **Automated Invoicing:** Quick bill generation using VBA macros and interactive buttons.
- 📦 **Inventory Tracking:** Automatic stock level updates and item price lookups.
- 📊 **Sales Summary & Reports:** Calculates daily total sales, discounts, and itemized billing summaries.
- 🔘 **User-Friendly Interface:** Custom macros and UserForms/buttons for fast navigation.

---

## 🛠️ Tech Stack & Tools
- **Software:** Microsoft Excel
- **Automation & Scripting:** VBA (Visual Basic for Applications) & Macros
- **Features & Formulas:** UserForms, VLOOKUP, INDEX/MATCH, Conditional Formatting, Data Validation

---

## 🚀 How to Run
1. Download or clone the `.xlsm` file from this repository.
2. Open the file in **Microsoft Excel**.
3. Click **"Enable Content"** or **"Enable Macros"** when prompted at the top of Excel to allow the VBA automation scripts to run.
